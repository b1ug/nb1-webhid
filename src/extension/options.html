Browser connection

Choose the light beside you.

The extension talks directly to blink(1) through WebHID. You do not need the native nb1 client.

Before connecting

Stop the native daemon and close other browser controllers of this light. WebHID does not participate in nb1's native ownership lock.

Only the blink(1) vendor/product is requested. Selection and opening send no color commands.

Not connected

Then use the toolbar

Open nb1 from Chrome's toolbar to set a color, turn the light off or start a timer. Closing the popup does not close the background connection.

This development preview supports exactly one granted blink(1). Browser restart, lost permission or unplugging requires explicit reconnection. No device storage is written.

Chrome must keep running. A timer interrupted by a background restart is cancelled, not replayed later.
