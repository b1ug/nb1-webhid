# 浏览器工作台与扩展计划

产品名称为 nb1。本开发预览项目包含网页和 Chrome 扩展，复用同一份固定提交的 Go 编译核心与 WebHID 传输层。

## 当前开发版本

网页默认英文，可显式切换中文；沿用定稿图标、本地字体和 JSON 编辑器。参数随当前动作显示，Play 自动 Go 校验并播放九种 Action 和 serial／interval 有限 Sequence；预览可选，JSON 默认收入高级区。导出的 `{ "sequence": ... }` 请求文件可以直接交给匹配的 API v1 nb1 预览、运行或保存为本机 Pattern。编辑、预览、导入和导出都不播放。

浏览器通过共用 Go 播放计划执行多 Step，显示就近进度并提供 Stop／Off。Stop 取消后续调度，当前硬件渐变可能继续；Off 另外熄灯。页面隐藏或离开即停止调度，不自动续播。选择设备与发送指令明确触发，未知结果不重试、不追加清理指令。

Chrome 扩展采用 Manifest V3，用户在扩展页面选择设备后交给后台。首阶段支持一只无歧义的已授权 blink(1)、手动设色／熄灯、分钟级倒计时、取消和状态。到时发送设色指令，灯保持至用户熄灯；这不是完整 Pattern 播放器。只申请 storage 与 alarms，不读取所有网页，不申请键盘、屏幕或原生消息权限。

首批交付包括本地网页、可解压加载的扩展 ZIP、来源记录、软件测试与 CI；不做商店上架，网页托管作为独立开发预览交付。

### 验收范围

软件验证包括 Go 原生／WASM 一致性、文件往返、预览不发硬件指令、准确 HID 报文、未知结果不重放、倒计时状态、英中界面与宽窄屏。实际扩展在独立浏览器 profile 中检查，模拟设备与真机严格分开标示。

真机单独开受控窗口：释放其他控制器，选择灯，检查 Set／Off／Fade，再关闭工具栏弹窗观察倒计时提醒，分别记录命令结果与相机画面。重启、睡眠、拔插、撤销授权和多控制器冲突需要额外证据；不会借用模拟测试给出实机结论。

## 后续阶段

1. 继续验证浏览器真机时序、光学、生命周期与设备能力预检。网页已复用 Go 计划；扩展仍是 Set／Off 和倒计时，多 Step 扩展播放留待后续，避免两边重复高级动作数学。
2. 加入用户按需授权的下载完成提醒、勿扰时段、事件去重和优先级；alarms 只触发提醒，不给灯效逐 Step 计时。
3. 增加明确域名白名单的网页任务消息，网页不能获得任意 HID 指令权限；扩展模式由扩展统一持有 USB。
4. 完成权限、隐私、安装、重启与真机验收后，再决定正式分发和公开发布。

## 不变的边界

浏览器不遵守 nb1 的原生进程锁，网页、扩展和 daemon 需要明确切换控制权。WebHID 没有通用 USB 串号属性，首阶段拒绝多只授权设备的歧义。断开不等于熄灯，未知写入不自动重试。浏览器存储和本机作品库分别管理，通过同格式文件衔接。系统级事件、CLI、Agent hook 和不依赖 Chrome 的常驻运行仍由原生 daemon 负责。
