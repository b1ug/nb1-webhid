# 浏览器播放

[English](PLAYBACK.md) · [安装与支持范围](DISTRIBUTION.zh-CN.md)

选择 Action，调整参数，点击 **Play**，当前输入会自动校验并编译；Preview 可选。单色动作显示一个颜色，Alternate／Orbit 显示两个，Rainbow／Off 不需要颜色。高级 JSON 接受既有 Action 或 Sequence 请求；一经编辑或导入，Play 与 Export 均以这份原文为准。

播放通过随包 Go／WASM 调用 nb1 的 sequence.Plan，展开有限循环，生成有序目标写入、serial 相对等待、每个 interval Step 的预算与最终渐变等待。浏览器不重新编写动作配方、颜色数学或时序常量，也没有改变原生 daemon 执行器或增加另一种创作格式。

播放前会通过 D(play=0,keep=1) 关闭此前的设备失联看门狗，并以 p(play=0) 停止自主播放，再发送 Go 计划中的渐变。不写 Pattern 行、Flash、Notes 或上电设置。正常结束方式 on_finish:off 在最后等待后向双灯发黑色；hold 保留最后输出。每次渐变由硬件完成。

**Stop** 阻止后续 Step，并等待正在执行的写入。它不能撤销已经发出的 USB 报文，也不能冻结已开始的硬件渐变。**Off** 停止后续 Step、等待在途写入，再显式发送黑色。Disconnect 先停止后续调度，再关闭设备句柄；即便在途写入失败，显式断开仍会尝试关闭。若无法确认关闭成功，界面会继续报告结果未知。隐藏或离开页面会停止调度，返回后不续播、不重放。

serial 等待从上一次写入返回后开始。interval 的每个 Step 从实际开始获得新的预算，并维持目标间距；写入预算过期便终止。最后一段渐变可以稳定完成后再做正常收尾。定时器延迟超过一秒同样终止，不会突发补发过去的 Step。播放时请保持页面可见；不依赖前台网页的运行交给原生 daemon。

未知 USB 结果不重试、不重连，也不追加自动清理指令。状态保持失败／未知，请显式断开后再决定是否重试。进度代表已接受的指令与主机等待，不是设备读回或光学测量。名义时长不包括 USB、前置操作、正常收尾与定时器迟到。

软件验证使用真实 Go 编译器、原生／WASM 一致性、实际播放器、手动时钟与假 HID。真实 USB、光学效果、浏览器生命周期和每代硬件仍需独立证据；模拟通过不等于上述项目验收。Chrome 扩展目前仍单独提供 Set／Off 与倒计时，网页的 Sequence 播放不代表扩展已经提供 Pattern 播放器。
